# Incoming — Drop New Data Here

Drag any new files into this folder for Gary to read and process.

## What to drop here

- Electrical schematics (PDFs, scanned drawings)
- Equipment manuals or datasheets
- Photos of plant and equipment
- Maintenance records or inspection reports
- Spreadsheets or CSV files with equipment data
- Any other documents relating to Seaforth Grain Terminal

## What happens next

Tell Gary (in the chat) what you have dropped in, and what you would like done with it.
For example:
- "I've dropped in new MCC4 drawings — add them to Switchrooms"
- "There are some motor datasheet PDFs — add them to Manuals"
- "I've added photos of the ship unloader — file them in Ship Unloader BMH/Photos"

Gary will read the files, process them, and move them to the correct location inside
the Grain Terminal folder. This Incoming folder is a temporary holding area only —
files will not stay here permanently.

After processing, items should be moved to `Incoming/Processed/` with a short audit note
so it is clear they have already been reviewed.

## Important

Do not rely on files in this folder for engineering reference.
Authoritative documents are in: Grain Terminal/Switchrooms, Grain Terminal/Equipment, etc.
