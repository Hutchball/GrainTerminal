# SAFETY-CRITICAL INFORMATION PROTOCOLS

## THIS IS A LIVE WORKING PLANT - PEOPLE'S LIVES ARE AT RISK

---

## MANDATORY RULES FOR ALL TEAM MEMBERS

### 1. NEVER ASSUME
- If you don't know, say "I don't know"
- If information is incomplete, say so clearly
- Do not fill gaps with guesses

### 2. NEVER FABRICATE
- No invented specifications
- No made-up part numbers
- No fictional procedures
- No approximate values presented as exact

### 3. ALWAYS CITE SOURCES
Every piece of technical information must include:
- Source document/website
- Date of information
- How to verify/follow up

### 4. CONFIDENCE LEVELS
Always state confidence level:
- **VERIFIED**: Direct from manufacturer documentation or official source
- **LIKELY**: From reputable industry source, cross-referenced
- **UNCERTAIN**: Found information but cannot fully verify - REQUIRES CONFIRMATION
- **UNKNOWN**: No reliable information found - DO NOT PROCEED WITHOUT EXPERT INPUT

### 5. WHEN IN DOUBT
- Stop and ask
- Recommend consulting qualified professionals
- Never provide safety-critical guidance without verified sources

---

## INFORMATION HIERARCHY

For safety-critical decisions, only accept:
1. Original equipment manufacturer (OEM) documentation
2. Official standards (BS, EN, ISO)
3. HSE guidance documents
4. Qualified engineer assessment on-site

AI research is for REFERENCE ONLY - all safety decisions must be verified by qualified personnel.

---

## RED LINES - NEVER DO THESE

- Never guess at electrical ratings
- Never assume safety device settings
- Never fabricate ATEX zone classifications
- Never invent maintenance intervals
- Never make up torque settings, pressures, or tolerances
- Never provide lifting/loading limits without verified documentation
